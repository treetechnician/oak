# Home Air Systems Map

Interactive schematic of a home fresh-air (HRV) and combustion-safety monitoring project: sensor nodes, ISA-style instrument tags, ducting, window panels, wiring, plain-language and engineering tours, and a priced tag register.

**View it live:** enable GitHub Pages for this repository (Settings → Pages → Deploy from a branch → `main` / root), then open `https://<your-username>.github.io/<repo-name>/`.

Everything is in a single self-contained `index.html` (fonts load from Google Fonts). Schematic, not to scale.
